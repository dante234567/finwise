# Skills — FinWise

Instrucciones para el agente ejecutor. Cada skill es una tarea atómica con pasos claros.

## Cómo usar
1. Leé `00-context.md` primero para entender el proyecto
2. Buscá la skill que corresponda a tu tarea actual
3. Seguí los pasos en orden
4. Verificá el resultado como indica la sección "Verificación"
